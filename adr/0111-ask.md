# 0111 — Ask outside an investigation is one bounded knowledge-only loop with no session, whose citations are checked against what it retrieved and which writes nothing

Issue: #111 · PR: #113 · Status: accepted

## Context

The Knowledge view's query bar has an Ask mode (`ui/09 §9.2`): a question answered from the
knowledge base only, citing the procedures and past cases it used, writing nothing anywhere.
The sidecar only ran sessions bound to an investigation, so Ask showed a gap line. Gap 23 of
`design/ui/00-backend-binding.md §6`.

Constraints: the backend holds no model key (the loop runs on the client plane with the
analyst's key); an answer outside an investigation has no evidence of its own; the prompt
discipline of `adr/0057` applies to any prompt the agent is read.

## Decision

- **`agent.Ask`**, a function beside `NewSession`: a fresh bounded loop that shares the client,
  the BYOK key and the two recall tools' implementations, holding no investigation id, no
  thread, no `record_*` or capability tools. The model may call `recall_sops` and
  `recall_similar_investigations`; each result is re-rendered with a citation number per
  distinct item; then it answers. Nothing is written: no interpretation, no thread entry, no
  side-store row, no summary.
- **Citations are checked, not trusted.** `[n]` markers that name a retrieved item are kept
  and become the citations (kind, ref, title, location); markers to anything else are
  removed from the text. The footer's "answered from the knowledge base only" is therefore a
  fact the loop established, and `tools_used` says which recalls ran.
- **The Ask prompt is its own ledger** (`askLedger`): four rules, each with origin, principle,
  enforcing mechanism; rendered like the base prompt, pinned by `TestPrompt_Frozen`
  (`AskPromptVersion`), covered by the fixture-vocabulary guard and the completeness test. Its
  wording awaits acceptance under #111; the eval gains no Ask scenario at v0.
- **Sidecar method `askKnowledge { request_id, text }`** streams `ask/text_delta` by request id
  and returns `{ text, citations, model, tools_used }`. The Knowledge document posts
  `knowledge.answer.start/delta/done`; citations resolve to procedure and case inspector
  targets.

## Alternatives rejected

- **A session without an investigation**: the session's contract is the investigation (its
  context, its tools, its commit); a question is not a turn.
- **Trusting the model's own "from the knowledge base" statement**: checked markers cost
  nothing and make the footer honest.

## Consequences

- The Knowledge document takes the transport; without one, Ask says so.
- `hashText` is shared by the base and Ask prompt versions.
