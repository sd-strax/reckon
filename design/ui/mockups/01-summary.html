What happened

drafted by reckon from the case record · edited by Sudeep

At 14:32:47 UTC the service account svc_backup opened an interactive RDP session on the file server WIN-FILE01 from 10.0.4.20, a workstation-subnet address. The account normally only makes network logons from BKP-01 during the nightly 02:00 backup.

Within the session, a process named mstsc-hijack.exe launched encoded PowerShell, and 15 seconds later the server connected to 185.220.101.5 (exfil.example.net) on 443. The backup team confirmed nobody was working on the server at that time. The PowerShell payload itself was harmless, but the session is consistent with someone using stolen svc_backup credentials.
