Isolate the destination host once hands-on-keyboard activity is confirmed, using network isolation so volatile evidence survives [1]. Then disable or force-reset the account, but first capture every host it has reached, or you lose the map; for a service account, coordinate the rotation, since a blind reset causes an outage and tips off the adversary [1] [2]. The May FINANCE-07 case followed the same order: isolate, then disable [3].

No procedure covers how to tell a backup service account's legitimate use from misuse.
