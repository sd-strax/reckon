Lateral Movement via RDP — Containment

by Sudeep · Oct 26

Scope: an interactive RDP logon from an internal host that is not a known jump box, followed by process creation on the destination. Treat as suspected hands-on-keyboard lateral movement (T1021.001) until proven benign.

Triage

  1. Confirm the source→destination RDP session in the authentication telemetry. Note the account and whether it holds local-admin on the destination.
  2. Pull process activity on the destination in the 15 minutes after the logon.
  3. Check whether the account authenticated to additional hosts in the same window.

Containment

  • Isolate the destination host if hands-on-keyboard activity is confirmed. Prefer network isolation over power-off.
  • Disable or force-reset the account if it is being used to pivot. Do not reset before capturing which hosts it has already reached.
  • Block the source host's RDP egress if the source itself is compromised.

Do not

  • Do not reimage the destination before evidence collection.
  • Do not treat a single logon as benign because the account is privileged.
